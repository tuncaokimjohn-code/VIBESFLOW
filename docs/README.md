## Reading the evidence correctly

A candidate's folder date indicates recorded filesystem activity, **not** the time an individual test ran or a formal approval. Builder tests do not automatically constitute independent QA. Simulated model messages are not genuine provider receipts. The protected saved genuine Muse result is evidence of a prior model operation; loading it in the browser does **not** send a new model request.

The public clean clone intentionally excludes API credentials, private authorization grants, consumed-operation locks and the saved genuine result. See the repository's root README for normal setup and qualified capabilities.

**Repository access note:** Publishing Markdown to a private repository does not make it visible to judges or the general public. Visibility must be handled separately by the owner after reviewing the source and its history.
